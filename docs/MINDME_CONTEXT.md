### 3. Functions

**카카오대화내용분석**
- 사건을 추출해서 그 시점의 나 를 추출해야한다 
- 카카오톡 TXT, 일기 등 

**사용자입력 프롬프트 분석**
- AI 기반 주요 사건·시점·감정·대화 맥락 추출
- 사건별 타임라인 자동 생성
- 사건 추가·수정·삭제

**페르소나추출**
- 입력된 프롬프트나 카카오 대화에서 페르소나 추출

**페르소나생성**
- 과거·현재·미래의 나 선택
- 기록 기반 성격·말투·기억·감정 자동 설정
- 페르소나 수정 및 확정

- 예시: 과거의 나
  - 특정 나이 선택 (예: 15살)
  - 특정 사건 선택 (예: 친구와 다툰 날)
  - 사건 발생 전·당시·직후 선택
  - 해당 시점의 성격·감정·기억 반영
  - 사건 선택 없이 자유 대화 가능

- 예시: 현재의 나
  - 현재 성격·가치관·고민 기반 생성
  - 현재 감정 및 상황 반영

- 예시: 미래의 나
  - 미래 나이 선택 (예: 30살)
  - 목표·가치관·희망하는 삶 입력
  - 가상의 미래 페르소나 생성



## 구현 반영 (Gate 2, apps/web)

- 흐름: 랜딩 → 만들기(카톡 TXT·사진·나의 이야기·이름·**현재 나이 입력**) → 진행 → 목록 → 모달(나이·상황) → 대화 → 프로필 시트.
- 처음 만들면 기록에서 **페르소나를 자동 추출해 최대 3개**(나이가 겹치지 않는 지난 사건 위주, 모자라면 '지금의 나')를 만들고 아바타도 함께 그린다.
- 모달에서 고른 나이가 지금보다 어리면 과거, 같으면 현재, 많으면 미래(상황을 목표로 사용)의 나가 된다.
- 대화 화면의 아바타를 누르면 **프로필 시트**에서 말투·기억 등을 고쳐 확정한다.
- 저장은 브라우저(localStorage)뿐이고 서버는 상태가 없다. AI 는 OpenAI 만 쓴다.
