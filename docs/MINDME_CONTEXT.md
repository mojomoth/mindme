### 2. Screens

**Landing**
- n초 후 페르소나 생성 화면 이동

**페르소나생성**
- 귀여운 가이드 캐릭터 
- 파일업로드(txt)
- 프롬프트입력(textarea)
- 내 얼굴 사진 업로드 (디폴트로 캐릭터 이미지)
- 생성버튼

**페르소나생성확인**
- 메신저 친구 목록과 같음
- 페르소나의 이름 (예: 15살의 홍길동, 000 사건의 김철수)
- 페르소나 생성 버튼 
  - 페르소나생성팝업표시
- 페르소나선택하면 대화창 

**페르소나생성팝업(모달)**
- 상황 설명 프롬프트 입력
- 나이 선택 슬라이드 
- 생성 버튼

**대화하기**
- 메신저 대화 화면과 같음 
- 상대방 프로필 사진(생성된 페르소나 이미지)
- 대화 버블 
- 대화 나가기 버튼

### 3. Functions

**카카오대화내용분석**
- 사건을 추출해서 그 시점의 나 를 추출해야한다 
- 카카오톡 TXT, 일기 등 

**사용자입력 프롬프트 분석**
- AI 기반 주요 사건·시점·감정·대화 맥락 추출
- 사건별 타임라인 자동 생성
- 사건 추가·수정·삭제

**페르소나추출**
- 입력된 프롬프트나 카카오 대화에서 페르소나 추출

**페르소나생성**
- 과거·현재·미래의 나 선택
- 기록 기반 성격·말투·기억·감정 자동 설정
- 페르소나 수정 및 확정

- 예시: 과거의 나
  - 특정 나이 선택 (예: 15살)
  - 특정 사건 선택 (예: 친구와 다툰 날)
  - 사건 발생 전·당시·직후 선택
  - 해당 시점의 성격·감정·기억 반영
  - 사건 선택 없이 자유 대화 가능

- 예시: 현재의 나
  - 현재 성격·가치관·고민 기반 생성
  - 현재 감정 및 상황 반영

- 예시: 미래의 나
  - 미래 나이 선택 (예: 30살)
  - 목표·가치관·희망하는 삶 입력
  - 가상의 미래 페르소나 생성
