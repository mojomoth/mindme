# HIL 체크리스트 — Gate 3 (https://mindme-rho.vercel.app)

사람이 직접 확인한다. 배포된 주소에서 실제 AI 를 부르므로 첫 생성에 1분 안팎이 걸린다. 같은 네트워크에서 10분에 analyze 10번을 넘기면 '잠시 뒤에 다시 시도해 주세요' 안내가 나온다.

## 접속
- [ ] 휴대폰·데스크톱 브라우저에서 주소가 열리고 01 랜딩이 보인다
- [ ] 로그인이나 접근 제한 화면 없이 열린다

## 플로우
- [ ] 02 에 실제 카카오톡 내보내기 TXT 를 올리고 '나의 이야기'를 쓴다
- [ ] 이름·지금 나이를 넣고 사진 없이 한 번, 내 얼굴 사진으로 한 번 만들어 본다
- [ ] 진행 화면이 단계별로 바뀌다가 03 목록으로 간다 (1분 안팎)
- [ ] 아바타가 나이대에 맞고, 사진을 올린 경우 나를 닮았다 (나이 차이가 약한 것은 알려진 P2)
- [ ] '새 나 만나기'로 과거·현재·미래를 하나씩 만든다
- [ ] 같은 사건으로 다시 만들면 '이미 있어요, 이어갈까요?' 안내가 나온다
- [ ] 대화에서 답이 글자 단위로 오고, 말투가 기록 속 나와 닮았다. 어색한 한국어가 없다
- [ ] 답이 오는 중에 나가기를 누르고 다시 들어가면 '다시 받기'로 이어진다
- [ ] 프로필 시트에서 말투·기억을 고쳐 확정하면 이후 대화에 반영된다
- [ ] 새로고침·브라우저를 닫았다 열어도 프로필·페르소나·대화가 남아 있다

## 실기기·환경
- [ ] iPhone·Android 실기기에서 상단·하단 safe-area(노치, 홈 바)에 내용이 가리지 않는다 (에뮬레이션으로는 확인 불가)
- [ ] 휴대폰에서 사진 선택 시 앨범·카메라 권한 안내가 정상이다
- [ ] 휴대폰 첫 화면이 3초 안에 보인다 (모바일 폰트·이미지 용량 P2)
- [ ] 네트워크를 끊고 대화하면 한국어 안내가 나온다
- [ ] 한국에서 대화 첫 글자가 몇 초 걸리는지 느낌을 적는다 (함수 리전 iad1)

## 보안·개인정보
- [ ] 개발자 도구 Network·Sources 에 API 키가 보이지 않는다
- [ ] 사진이 서버에 남지 않고 브라우저 저장소에만 있음을 알고 있다 (공용 기기에서는 쓰지 않기)
