# HIL 체크리스트 — Gate 2 (http://localhost:3100)

사람이 직접 확인한다. 기다리지 않고 Gate 3 으로 진행한다. 실제 AI 를 부르므로 첫 생성에 1분 안팎이 걸린다.

## 서버
- [ ] `pnpm dev:web` 으로 3100 이 열린다

## 플로우
- [ ] 01 랜딩에서 시작 버튼이 02 로 이어진다
- [ ] 02 에 실제 카카오톡 내보내기 TXT 를 올리고 '나의 이야기'를 쓴다
- [ ] 이름과 지금 나이를 넣는다. 내 얼굴 사진도 올려 본다(없이도 해 본다)
- [ ] 진행 화면이 단계별로 바뀌다가 03 목록으로 간다
- [ ] 목록에 페르소나가 최대 3개 보이고 이름·미리보기가 자연스럽다
- [ ] 아바타가 나이대에 맞고, 내 얼굴을 닮았다(사진을 올린 경우)
- [ ] '새 나 만나기' 모달에서 지금보다 어린 나이를 고르면 과거, 같으면 현재, 많으면 미래가 만들어진다
- [ ] 같은 사건으로 다시 만들면 이름이 같은 페르소나가 생긴다 (알려진 P2)
- [ ] 목록에서 하나를 눌러 05 대화로 들어간다. 첫 인사가 나온다
- [ ] 메시지를 보내면 답이 스트리밍으로 오고 맨 아래로 스크롤된다
- [ ] 말투가 기록 속 나와 닮았다. 어색한 한국어가 없다
- [ ] 아바타를 눌러 프로필 시트를 열고 말투·기억을 고쳐 확정하면 이후 대화에 반영된다
- [ ] 나가기 후 목록에서 다시 들어가면 대화가 남아 있다
- [ ] 새로고침해도 프로필·페르소나·대화가 복원된다
- [ ] 답이 오는 중에 나가기를 누르면 어떻게 되는지 본다 (알려진 P2)

## 환경
- [ ] 휴대폰 너비(360~430px)에서 전체 화면이 쓸 만하다
- [ ] 네트워크를 끊고 대화하면 한국어 안내가 나온다
- [ ] 브라우저 개발자 도구 Network 에 API 키가 보이지 않는다
