     1	# 최소 API 계약 (v1, Gate 1 실측 기준)
     2	
     3	- 코드 기준: `packages/core/src/schemas.ts`(zod)와 `packages/core/src/persona/persona.ts`(`PersonaGenerateRequestSchema`). 이 문서와 1:1 이다. 한쪽을 바꾸면 다른 쪽도 같이 바꾼다.
     4	- Route Handler(`pocs/app/api/**/route.ts`)는 얇게 둔다: `parseRequest`(본문 상한 → JSON → zod) → 키 확인 → core 함수 → 응답. 공통 처리는 `packages/core/src/server/http.ts`, 대화 스트림은 `packages/core/src/chat/server.ts`.
     5	- 모든 Route Handler 는 서버 전용이다. AI 키는 서버(`@mindme/core/server`)에서만 읽고, AI 호출은 모두 `packages/core/src/server/llm.ts`(OpenAI) 를 거친다.
     6	- 서버는 상태를 저장하지 않는다. 사건·페르소나·대화 기록은 클라이언트(localStorage)가 보관하고, 필요한 만큼 요청 본문에 실어 보낸다.
     7	- 문자열 필드는 앞뒤 공백을 지운 뒤 검사한다. 아래 `≤n` 은 글자 수(UTF-16 길이) 상한이고, `text` 표시는 빈 문자열을 허용하지 않는다는 뜻이다.

   137	## POST /api/persona
   138	
   139	선택한 시점의 '나'를 만든다. core: `generatePersona(data)`.
   140	
   141	요청 (`PersonaGenerateRequestSchema` = `PersonaRequestSchema` + `event`, `futureGoals`)
   142	
   143	```json
   144	{
   145	  "kind": "past",
   146	  "age": 15,
   147	  "eventId": "evt_01",
   148	  "phase": "after",
   149	  "situation": "민수랑 싸우고 집에 돌아온 저녁",
   150	  "events": [ /* Event[] — /api/analyze 결과(수정본) */ ],

   154	
   155	| 필드 | 형식 | 설명 |
   156	|---|---|---|
   157	| `kind` | PersonaKind | |
   158	| `age` | Age | 만들 인물의 나이. `present` 는 클라이언트가 `profile.currentAge` 와 같게 보낸다(서버는 검사하지 않음) |
   159	| `eventId?` | text ≤64 | `past` 에서 `events` 안의 사건 id. 없으면 400 `선택한 사건을 events 에서 찾지 못했어요.` |
   160	| `event?` | Event | 분석 결과 없이 사건 하나를 직접 넘길 때. `eventId` 보다 우선 |
   161	| `phase?` | Phase | `past` + 사건이 있을 때. 기본 `after` |
   162	| `situation` | string ≤2000, 기본 `""` | 상황 설명 |
   163	| `events` | Event[] ≤100, 기본 `[]` | 사건 없이도 생성 가능(자유 대화) |
   164	| `futureGoals?` | string ≤2000 | `future` 의 목표·가치관·바라는 삶 |
   165	| `profile` | Profile | |
   166	
   167	- `past`: 그 나이 이후 사건과 나이를 알 수 없는 사건은 AI 에 넘기지 않는다(선택한 사건은 항상 넘김). `before` 는 사건 내용을 숨기고 분위기만 준다. `profile.currentAge` 가 있고 `age > currentAge` 면 400 `과거의 나는 지금 나이보다 어려야 해요.`
   168	- `present`: 현재 성격·가치관·고민 기반. `eventId`·`phase` 는 쓰지 않는다
   169	- `future`: `futureGoals`(와 `situation`)를 바탕으로 한 가상 인물, 예언 금지. `currentAge` 가 있고 `age ≤ currentAge` 면 400 `미래의 나는 지금 나이보다 많아야 해요.`
   170	- AI 초안은 Persona 상한으로 자르고 줄바꿈을 한 칸 공백으로 편다. 빈 greeting 은 `…왔어?`

   194	## POST /api/persona/avatar
   195	
   196	얼굴 사진으로 해당 나이의 3D 아바타를 만든다(gpt-image-2 편집, 스타일 참조 `assets/generated/avatar-teen-512.png`). 사진이 없으면 AI 를 부르지 않고 기본 캐릭터를 돌려준다. 사진은 메모리에서만 쓰고 저장하지 않는다.
   197	
   198	요청 (`AvatarRequestSchema`)
   199	
   200	```json
   201	{ "age": 15, "kind": "past", "photo": "data:image/jpeg;base64,/9j/…" }
   202	```
   203	
   204	- `photo`(선택): `data:image/(jpeg|png|webp);base64,…`, ≤5,600,000자. 클라이언트가 긴 변 1024px JPEG 로 줄여 보낸다(보통 300KB 안팎)
   205	- 검증 실패는 고정 문구 400 `age(1~120), kind(past|present|future), photo(JPG·PNG·WEBP data URL)를 확인해 주세요.`
   206

   208	
   209	```json
   210	{ "avatar": "data:image/webp;base64,…", "source": "generated" }

   214	{ "avatar": "/_next/static/media/guide-face-512.<hash>.png", "source": "default" }
   215	```
   216	
   217	- 생성 시 헤더 `Server-Timing: gen;dur=<ms>` (실측 30~35s)
   218	- `default` 경로는 빌드마다 해시가 바뀐다. 오래 보관하지 않는다(P2)
   219	- 오류: 413 `사진이 너무 커요. 더 작은 사진으로 해 주세요.`, AI 오류 → 502 `아바타를 만들지 못했어요. …`

   221	## POST /api/chat
   222	
   223	페르소나와 대화한다. 응답은 스트리밍 텍스트다. core: `chatResponse(data)`.
   224	
   225	요청 (`ChatRequestSchema`)
   226	
   227	```json
   228	{
   229	  "persona": { /* Persona */ },
   230	  "messages": [
   231	    { "role": "assistant", "content": "…왔어? 오늘 좀 기분이 별로야." },
   232	    { "role": "user", "content": "그때 기분은 어땠어?" }
   233	  ]
   234	}
   235	```
   236	
   237	- `persona` 를 빼면 내장 샘플 `SAMPLE_PERSONA`(15살의 홍길동)로 대화한다
   238	- `messages` 1~100개, 마지막은 반드시 `user`(아니면 400 `마지막 메시지는 user 여야 합니다.`)
   239	- 대화 기록은 클라이언트가 보관하고 매번 보낸다(PoC 화면은 최근 40개). 서버는 AI 에 최근 24개·합계 12,000자까지만 보낸다(마지막 user 는 항상 포함)
   240	- persona 문자열은 시스템 프롬프트에 들어가기 전에 줄바꿈·대괄호·따옴표를 공백으로 바꾼다
   241	
   242	응답 200
   243	
   244	- `Content-Type: text/plain; charset=utf-8`, `Cache-Control: no-store`, 청크 단위 스트림 (페르소나 답변 본문만)
   245	- `X-Crisis: 1|0`: 마지막 user 메시지에 자해·자살 키워드가 있으면 1. 이때 응답 끝에 109 안내(`CRISIS_FOOTER`)를 한 번 붙인다(모델이 이미 109 를 썼으면 생략)
   246	- 첫 청크를 받을 때까지 기다린다. 시작 전 오류는 502 `답변을 만들지 못했어요. …` JSON, 스트림 도중 오류는 연결 종료로 알린다
   247	- 오류: 413 `요청 본문이 너무 큽니다.`

     8	type ParseOpts = {
     9	  /** 본문 상한(UTF-16 길이). 넘으면 413 */
    10	  maxBody: number;
    11	  /** 413 문구 */
    12	  tooLarge?: string;
    13	  /** 400 문구. 'path'(기본) = `경로: zod 메시지`, 'message' = zod 메시지만, 그 밖의 문자열 = 고정 문구 */
    14	  invalid?: 'path' | 'message' | (string & {});
    15	  /** 검증 전에 본문을 손본다 (예: 빠진 값 기본값 채우기) */
    16	  prepare?: (body: Record<string, unknown>) => unknown;
    17	};
    18	
    19	/** 성공하면 { data }, 실패하면 그대로 돌려줄 { error: Response }. */
    20	export async function parseRequest<S extends z.ZodType>(
    21	  req: Request,
    22	  schema: S,
    23	  opts: ParseOpts,
    24	): Promise<{ data: z.infer<S>; error?: undefined } | { data?: undefined; error: Response }> {
    25	  const raw = await req.text();
    26	  if (raw.length > opts.maxBody) return { error: fail(413, 'payload_too_large', opts.tooLarge ?? '요청 본문이 너무 큽니다.') };
    27	
    28	  let body: unknown;
    29	  try {
    30	    body = JSON.parse(raw);
    31	  } catch {
    32	    return { error: fail(400, 'invalid_request', 'JSON 형식이 아닙니다.') };
    33	  }
    34	  if (opts.prepare) body = opts.prepare(body && typeof body === 'object' ? (body as Record<string, unknown>) : {});
    35	
    36	  const parsed = schema.safeParse(body);
    37	  if (parsed.success) return { data: parsed.data };
    38	  const issue = parsed.error.issues[0];
    39	  const mode = opts.invalid ?? 'path';
    40	  const message =
    41	    mode === 'path'
    42	      ? issue ? `${issue.path.join('.')}: ${issue.message}` : '요청이 올바르지 않습니다.'
    43	      : mode === 'message'
    44	        ? (issue?.message ?? '요청이 올바르지 않습니다.')
    45	        : mode;
    46	  return { error: fail(400, 'invalid_request', message) };
    47	}

     2	import type { ChatRequest } from '../schemas.ts';
     3	import { streamText } from '../server/llm.ts';
     4	import { fail } from '../server/http.ts';
     5	import { buildSystemPrompt, CRISIS_FOOTER, detectCrisis, trimMessages } from './index.ts';
     6	
     7	/**
     8	 * 검증 끝난 요청 → text/plain 스트림 응답 (POST /api/chat).
     9	 * 첫 청크까지 기다려서, 시작 전 공급자 오류는 공통 에러 JSON(502)으로 돌려준다. 이후 오류는 연결 종료.
    10	 * 위기 신호면 응답 끝에 109 안내를 한 번만 붙이고(모델이 이미 썼으면 생략) X-Crisis 헤더로 알린다.
    11	 */
    12	export async function chatResponse({ persona, messages }: ChatRequest): Promise<Response> {
    13	  const crisis = detectCrisis(messages.at(-1)!.content);
    14	  const reader = streamText({
    15	    system: buildSystemPrompt(persona, { crisis }),
    16	    messages: trimMessages(messages),
    17	  }).getReader();
    18	
    19	  let first: ReadableStreamReadResult<Uint8Array>;
    20	  try {
    21	    first = await reader.read();
    22	  } catch {
    23	    return fail(502, 'upstream_error', '답변을 만들지 못했어요. 잠시 뒤 다시 시도해 주세요.');
    24	  }
    25	
    26	  const decoder = new TextDecoder();
    27	  const encoder = new TextEncoder();
    28	  let text = '';
    29	  const stream = new ReadableStream<Uint8Array>({
    30	    start(c) {
    31	      if (first.value) {
    32	        text += decoder.decode(first.value, { stream: true });
    33	        c.enqueue(first.value);
    34	      }
    35	    },
    36	    async pull(c) {
    37	      const { done, value } = await reader.read();
    38	      if (!done) {
    39	        text += decoder.decode(value, { stream: true });
    40	        c.enqueue(value);
    41	        return;
    42	      }
    43	      if (crisis && !text.includes('109')) c.enqueue(encoder.encode(CRISIS_FOOTER));
    44	      c.close();
    45	    },
    46	    cancel(reason) {
    47	      return reader.cancel(reason);
    48	    },
    49	  });
    50	
    51	  return new Response(stream, {
    52	    headers: { 'Content-Type': 'text/plain; charset=utf-8', 'Cache-Control': 'no-store', 'X-Crisis': crisis ? '1' : '0' },
    53	  });
    54	}

   148	export function buildPersonaInput(req: ParsedRequest, picked?: TimelineEvent | null): string {
   149	  const visible = visibleEvents(req, picked);
   150	  const pickedVisible = req.phase === 'before' ? visible.filter(({ event }) => event.id !== picked?.id) : visible;
   151	  const sections = [
   152	    req.kind === 'past' ? pastBlock(req, picked) : req.kind === 'present' ? presentBlock(req) : futureBlock(req),
   153	    picked && req.phase !== 'before' ? `\n[선택한 사건]\n${fmtEvent(picked, eventAgeOf(picked, req.profile))}` : '',
   154	    picked && req.phase === 'before' ? `\n[곧 일어날 사건 — 인물은 모름, 분위기 참고용]\n- ${picked.title} (${picked.date})` : '',
   155	    req.profile.story ? `\n[나의 이야기]\n${req.profile.story}` : '',
   156	    req.situation.trim() ? `\n[상황 설명]\n${req.situation.trim()}` : '',
   157	    req.kind === 'future' && req.futureGoals?.trim() ? `\n[목표·가치관·바라는 삶]\n${req.futureGoals.trim()}` : '',
   158	    pickedVisible.length
   159	      ? `\n[기록 — 이 인물이 아는 일]\n${pickedVisible.map(({ event, age }) => fmtEvent(event, age)).join('\n')}`
   160	      : '\n[기록 없음]',

   142	export function kakaoDayBlocks(chat: KakaoChat): string[] {
   143	  const blocks: string[] = [];
   144	  let day = '';
   145	  for (const msg of chat.messages) {
   146	    if (msg.date !== day) {
   147	      day = msg.date;
   148	      blocks.push(`## ${day}`);
   149	    }
   150	    const who = msg.author === chat.me ? `${msg.author}(나)` : msg.author;
   151	    blocks[blocks.length - 1] += `\n${msg.time} ${who}: ${msg.text.replace(/\n+/g, ' / ')}`;
   152	  }
   153	  return blocks;
   154	}

   156	/**
   157	 * 블록을 순서대로 max 글자 이하 묶음으로 담는다.
   158	 * 블록 하나가 max 보다 크면 줄 단위로 나누고 조각마다 날짜 머리줄('## …')을 다시 붙인다. 줄 하나도 크면 글자 단위로 자른다.
   159	 */
   160	export function packChunks(blocks: string[], max: number): string[] {
   161	  const chunks: string[] = [];
   162	  for (const piece of blocks.flatMap((b) => splitBlock(b, max))) {
   163	    const last = chunks.at(-1);
   164	    if (last !== undefined && last.length + 1 + piece.length <= max) chunks[chunks.length - 1] = `${last}\n${piece}`;
   165	    else chunks.push(piece);
   166	  }
   167	  return chunks;
   168	}

   170	function splitBlock(block: string, max: number): string[] {
   171	  if (block.length <= max) return [block];
   172	  const lines = block.split('\n');
   173	  const head = lines[0]!.startsWith('## ') && lines[0]!.length < max / 2 ? lines.shift()! : '';
   174	  const room = head ? max - head.length - 1 : max;
   175	  const parts = lines.flatMap((l) => (l.length <= room ? [l] : (l.match(new RegExp(`[\\s\\S]{1,${room}}`, 'g')) ?? [])));
   176	  return packChunks(parts, room).map((c) => (head ? `${head}\n${c}` : c));
   177	}
