점수: 6/10

차이:
- **아바타가 전부 같은 마스코트**: 드래프트는 카드마다 다른 캐릭터입니다(파란 후드 소년, 직장인 소년, 새싹 마스코트). 실행 화면은 세 카드 모두 같은 마스코트입니다. 사진이 없어서 생기는 차이라 감점은 약하게 봤습니다. 다만 카드끼리 구분이 안 되고 화면이 단조로워 보입니다.
- **"새로운 페르소나" 배지가 모든 카드에 붙음**: 드래프트는 첫 카드에만 주황 점과 라벨이 있고 나머지 둘은 제목과 부제뿐입니다. 실행 화면은 세 카드 모두 표시되어 위계가 무너지고 카드가 더 빽빽해 보입니다. 데이터 상태 차이일 수 있지만, 표시 규칙이 다르면 실제 결함입니다.
- **카드 높이와 여백이 작음**: 드래프트 카드는 높이가 넉넉하고(배지 없는 카드는 더 낮음) 카드 사이 간격도 큽니다. 실행 화면은 카드가 더 납작하고 간격이 촘촘합니다. 아바타 원도 상대적으로 작고 카드 안쪽 패딩이 좁습니다. 실행 화면은 해상도가 다르므로 비율로 비교했습니다.
- **상단 영역의 세로 리듬이 더 빡빡함**: 드래프트는 타이틀, 완료 pill, 헤드라인 사이에 여유가 있고 헤드라인 크기도 비율상 약간 더 큽니다. 실행 화면은 상태바가 없어 전체가 위로 당겨졌고, 마스코트가 헤드라인 쪽으로 붙어 있습니다. 부제와 "페르소나 3" 라벨 사이 간격도 좁습니다.
- **마스코트 일러스트**: 드래프트는 오른쪽에서 헤드라인과 떨어져 있고 스파클이 두 줄입니다. 실행 화면은 마스코트가 조금 더 크고 왼쪽으로 와서 부제 끝(`선택해 주세요`)과 거의 닿습니다. 스파클은 짧은 한 줄뿐이고 바닥 그림자는 비슷합니다.
- **하단 영역**: 드래프트는 카드 목록 아래 빈 공간이 적고 하단 마스코트와 문구, CTA가 목록 가까이에 있습니다. 실행 화면은 카드가 3개로 끝난 뒤 빈 공간이 크고 하단 블록이 아래로 밀려 있습니다. CTA 버튼은 모양, 색, 그림자가 거의 같고 실행 쪽이 약간 낮습니다.
- **카드 그림자와 배경**: 드래프트는 카드 그림자가 부드럽고 배경 그라데이션이 은은합니다. 실행 화면은 배경이 거의 단색에 가깝고 그림자가 더 약해서 카드가 덜 떠 보입니다. 큰 차이는 아닙니다.

판단: 구성 요소, 색, 서체, 모서리 반경, CTA 스타일은 거의 일치해서 같은 화면 계열로 볼 수 있습니다. 다만 모든 카드에 배지가 붙는 점, 카드 높이와 여백이 작은 점, 마스코트가 텍스트에 붙는 점 때문에 드래프트의 여유로운 위계와 시각적 완성도는 아직 못 따라갑니다.
