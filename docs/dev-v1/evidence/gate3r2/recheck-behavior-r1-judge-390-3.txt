- 아바타: 원본은 카드마다 서로 다른 캐릭터(파란 후드 남학생, 가방 멘 직장인, 새싹 마스코트)를 씁니다. 실행본은 세 카드 모두 같은 마스코트이고 배경색만 파랑·노랑·분홍으로 다릅니다. 사진을 올리지 않아서 생긴 차이이므로 감점하지 않았습니다.
- 카드 순서: 원본은 15살 → 첫 출근 → 졸업식이고, 실행본은 15살 → 졸업식 → 첫 출근입니다. 데이터 차이로 봤습니다.
- 카드 높이와 간격: 실행본은 두 번째·세 번째 카드의 높이와 카드 사이 간격이 원본보다 약간 작습니다. "새로운 페르소나" 줄이 없는 카드는 원본이 더 여유롭습니다. 원본은 카드가 더 크고 그림자가 더 부드럽습니다.
- 세로 비율: 원본은 헤더가 상태바 아래로 내려가 있어서 상단 여백이 큽니다. 실행본은 상태바가 없어서 전체가 위로 올라갑니다. 그 결과 카드 아래의 빈 공간이 원본보다 넓어 보입니다. 이 부분은 감점하지 않았습니다.
- 히어로 마스코트: 구성과 위치는 같습니다. 실행본은 크기가 조금 작고 광택과 질감이 단순하며, 아래 파란 그림자도 더 옅습니다.
- 서체: 두 화면 모두 굵은 제목과 얇은 부제 위계를 따릅니다. 실행본 제목은 글자 두께와 자간이 조금 다르고 약간 더 무거워 보입니다.
- 하단 CTA 영역: 하단 마스코트와 안내 문구, 주황 알약형 버튼은 같습니다. 실행본은 버튼이 화면 바닥에 더 가깝고 버튼 높이가 조금 작습니다.

판단: 상단 타이틀과 체크 배지, 히어로 영역, 카드 목록, 하단 CTA까지 구성·색·모서리·위계가 거의 같아서 같은 화면으로 볼 수 있습니다. 남은 차이는 카드 높이와 간격, 마스코트 질감 같은 미세 조정 수준입니다.
