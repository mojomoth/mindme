차이:
- **상단 "페르소나가 준비됐어요" 알약 배지 없음**: 원본에는 제목 아래에 체크 아이콘이 붙은 흰색 알약 배지가 있습니다. 실행 화면에는 이 배지가 없고, 그래서 히어로 영역이 위로 당겨져 있습니다.
- **카드 내용 길이와 줄바꿈**: 원본 카드는 제목 1줄에 부제 1줄이고, 카드 높이는 약 100~110px로 낮고 일정합니다. 실행 화면은 제목이 2줄로 넘어가고 부제도 2줄로 말줄임(…)되어 카드가 훨씬 높고 빽빽합니다. 위계가 "제목 하나에 가벼운 부제 하나"에서 "텍스트 덩어리"로 바뀌었습니다. 데이터 차이로 볼 수도 있지만, 줄 수 제한과 말줄임 처리 방식이 달라 레이아웃에 영향을 줍니다.
- **카드 "새로운 페르소나" 상태 표시 없음**: 원본 첫 카드에는 주황 점과 "새로운 페르소나" 라벨이 있습니다. 실행 화면에는 없습니다.
- **하단 마스코트 문구와 가림**: 원본에는 "다른 순간의 나도 만나보세요" 문구와 마스코트가 CTA 위에 온전히 보입니다. 실행 화면에서는 마스코트가 CTA 버튼에 가려 윗부분만 보이고 문구는 보이지 않습니다. 카드가 길어져 밀린 것으로 보이며, 스크롤 영역과 고정 CTA가 겹칩니다.
- **히어로 영역 크기와 배치**: 마스코트와 제목 비율은 비슷하지만, 실행 화면에서는 제목 상단 여백이 작고 마스코트가 더 크며 우측 상단에 바짝 붙어 있습니다. 반짝이 장식도 원본(2줄)보다 작고 단순합니다.
- **카드 아바타**: 원본은 카드마다 서로 다른 캐릭터와 파스텔 배경(파랑, 노랑, 분홍)입니다. 실행 화면은 모두 같은 마스코트에 파란 배경이라 단조롭습니다. 사진 미등록 때문에 생긴 차이일 가능성이 높아 감점은 약하게 봤습니다.
- **카드 모서리와 그림자**: 원본은 모서리가 약간 더 크고 그림자가 아주 옅게 퍼집니다. 실행 화면도 비슷하지만 그림자가 거의 없어 더 평평합니다. 사소한 차이입니다.
- **카드 간격과 좌우 여백**: 대체로 비슷합니다. 다만 실행 화면은 카드 사이 간격이 약간 좁습니다.

판단: 색, 서체, 헤더, CTA 버튼, 카드 구조는 같은 화면으로 읽힙니다. 하지만 준비 완료 배지, "새로운 페르소나" 라벨, 하단 안내 문구가 빠졌고, 카드 텍스트가 길어져 위계와 밀도가 달라졌습니다. 그래서 같은 디자인의 완성 구현으로 보기에는 부족합니다.
