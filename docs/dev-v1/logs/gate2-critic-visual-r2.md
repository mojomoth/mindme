## P2

1. **긴 이름일 때 페르소나 이름 가운데가 잘린다(r1과 같음).** 목록·헤더·시트 이름 칸에 `졸업하며 서진과 헤어짐을 아쉬워…의 남궁하늘빛초롱별…`처럼 말줄임이 두 번 들어간다. core `personaName`이 40자에 맞추려고 사건 제목을 자르기 때문이다. 레이아웃은 깨지지 않는다(`critic-visual-r2-mobile-03-list.png`, `-06-profile-sheet.png`).
2. **03 하단 안내('다른 순간의 나도 만나보세요')가 첫 화면에서 생성 버튼에 가린다(r1과 같음).** 페르소나가 3개 이상이면 스크롤해야 보인다(`critic-visual-r2-desktop-03-list.png`, `-03s-bottom.png`).
3. **02 모바일 첫 화면에서 사진 카드가 생성 버튼 뒤에 있다(r1과 같음).** 360x740에서는 이름·나이 줄까지 버튼에 걸린다(`critic-visual-r2-mobile360-02-create.png`). 스크롤하면 모두 보이고 누를 수 있다.
4. **여러 줄 입력란이 안에서 스크롤될 때 위아래 줄이 반쯤 보인다(r1과 같음).** 04 상황 설명과 시트의 말투·기억 칸이 그렇다. 두 모델이 모두 지적했다.
5. **프로필 시트가 일반 설정 폼처럼 보인다(r1과 같음).** Sonnet 6점, Codex 8점이다. 색·모서리·버튼은 드래프트와 같다. 문구('쉼표로 나눠 적어요', '한 줄에 하나씩')는 자연스럽고 상투적인 표현은 없다.
6. **(새) 데스크톱 02 맨 아래 상태에서 마스코트 발과 말풍선 아랫부분이 상태바 경계에서 잘려 보인다.** 폼을 다 채우면 자동으로 이 상태가 된다(`critic-visual-r2-desktop-02-create.png`). 덮개를 깐 수정의 부작용이다. 겹침은 없고 일반 앱의 스크롤 모습과 같아 P2로 둔다. 경계에 짧은 페이드를 주면 덜 딱딱해 보인다.
7. **hallmark '리터럴 색 금지'(r1과 같음):** `Working.module.css`에 hex 6곳, `ProfileSheet.module.css`에 hex 10곳이 남아 있다. 화면에 보이는 문제는 아니다.

진행 화면은 두 모델 모두 8~9점으로 어울린다고 봤다. 문구('1~2분쯤 걸려요. 화면을 켜 둔 채 기다려 주세요.', '30초에서 1분쯤 걸려요.', '앞으로의 나를 만나러 가는 중')도 no-ai-slop 체크리스트에 걸리지 않는다.
