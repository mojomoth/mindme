## 발견 (P2 — 기록 후 진행 가능)

1. **스트리밍 중 나가면 그 질문이 답 없이 남는다.** 보낸 직후 `나가기` → 다시 들어가면 마지막 말풍선이 내 질문인데 답도 안내도 `다시 받기` 도 없다(`afterMidStreamReopen: {lastIsMine: true, alert: 0, retry: 0}`, `desktop-23`, `mobile-24`). 다시 보내면 이어지므로 막히지는 않는다. 다시 열 때 마지막이 내 말이면 `다시 받기` 를 보여 주는 정도면 된다.
2. **같은 사건으로 모달을 쓰면 이름이 똑같은 페르소나가 생긴다.** 14살·예고 상황으로 만들면 첫 생성과 같은 `evt_01` 에 이어져 `예고 진학 문제로 엄마와 다툰 밤의 한도윤` 이 두 개(`desktop-10-list-after-future.png`). photo 실행의 18살도 같음. 미리보기 문장으로만 구별된다.
3. **페르소나 실패 후 다시 시도하면 이미 성공한 아바타도 다시 그린다.** 모달 생성에서 `/api/persona` 만 실패해도 `다시 시도` 가 아바타 호출(약 30초·이미지 비용)을 다시 한다(retry 28.5s). 기록 분석은 이미 캐시하므로 같은 방식으로 아바타 결과를 들고 있으면 된다.
