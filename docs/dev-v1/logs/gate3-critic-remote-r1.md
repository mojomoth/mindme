1. `/api/persona` 400 문구가 필드 이름을 드러낸다: `선택한 사건을 events 에서 찾지 못했어요.` 앱 흐름에서는 나오지 않고 API 를 직접 부를 때만 보인다.
2. api.md 는 `/api/chat` 에서 `persona` 를 빼면 샘플로 대화한다고 적었지만, 배포(apps/web)는 `persona` 가 없으면 400 "대화 내용을 보내지 못했어요…" 다. 문서와 동작이 다르다.
3. 함수 리전이 iad1(미국 동부)이다. 한국 사용자는 요청마다 왕복 지연이 붙는다(OpenAI 도 미국이라 실제 손해는 작다). 대화 첫 글자는 1.3~5.5초였다.
4. maxDuration 실제 적용값(analyze 300초 등)은 배포 API 응답에 나오지 않아 직접 확인하지 못했다. 30만 자도 32초에 끝나서 60초를 넘는 경우를 만들지 못했다.
5. 큰 입력(구간 요약 모드)에서 `owner.currentAge` 가 null 이다(알려진 P2). 앱은 지금 나이를 직접 받으므로 흐름은 막히지 않는다.
6. 얼굴 사진이 브라우저 localStorage `mindme:photo` 에 data URL 로 남는다. 서버에는 남지 않지만 같은 기기를 쓰는 사람은 볼 수 있다.
