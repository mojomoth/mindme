## 6. 속도 제한·크기 제한 (`critic-local-r1-limits.txt`)

- 잘못된 JSON 으로 AI 호출 없이 횟수만 썼다. IP 는 `x-forwarded-for` 로 따로 줬다.
  - analyze 10, persona 30, avatar 15, chat 100 회까지 400 이고, 그다음 요청은 모두 **429**, `retry-after: 600`, "짧은 시간에 요청이 많았어요. 10분쯤 뒤에 다시 시도해 주세요." 가 나왔다. 다른 IP 는 따로 센다(400).
- 크기 제한
  - `/api/chat` 3.3MB: Content-Length 선검사에서 **413** "보낸 내용이 너무 길어요. 조금 줄여서 다시 보내 주세요."
  - `/api/analyze` ASCII 75만 자(바이트 상한 아래, 글자 상한 위): **413** "입력이 너무 길어요. 30만 자 이하로 줄여 주세요."
  - `/api/persona/avatar` 6MB: **413** "사진이 너무 커요. 더 작은 사진으로 해 주세요."
- 브라우저에서 429 를 받으면 서버 문구가 그대로 보인다(3장).
